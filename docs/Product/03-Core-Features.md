# Core Features

> "Every feature should help people discover the universe."

---

# Purpose

AstroAlert is built around a collection of carefully designed features that transform astronomical information into meaningful experiences.

Each feature exists to support the platform's mission of making astronomy accessible, engaging and scientifically accurate.

No feature is included simply because it is interesting.

Every feature must solve a real need, inspire curiosity or encourage exploration.

Together, these features create an ecosystem where users can learn, observe and experience the universe from a single platform.

---

# Content

## Home

The Home page is the entry point to AstroAlert.

It provides a clear overview of the most important astronomical information available at the current moment.

Its objective is to immediately answer the question:

**"What is happening in the universe right now?"**

---

## International Space Station (ISS)

The ISS section provides real-time information about the International Space Station.

Users can track its position, visibility and orbital data through an intuitive interface designed for both beginners and enthusiasts.

The goal is to connect users with one of humanity's greatest achievements in space exploration.

---

## Visible Planets

This section helps users discover which planets can currently be observed from their location.

Instead of presenting raw astronomical data, the information is translated into practical observation guidance.

Users should quickly understand what they can see and why it is visible.

---

## Eclipses

The Eclipses section presents upcoming solar and lunar eclipses with accurate dates, visibility information and educational explanations.

Beyond announcing events, this section should help users understand why eclipses occur and what makes each one unique.

---

## Conjunctions

This feature highlights upcoming planetary conjunctions and notable celestial alignments.

Users can discover when planets or celestial bodies appear close together in the sky and learn about the astronomical mechanics behind these events.

---

## Comets

The Comets section introduces both current and historically significant comets.

It provides visibility information, orbital details and scientific context while encouraging users to observe these rare visitors whenever possible.

---

## Moon

The Moon section offers information about the current lunar phase, illumination, upcoming phases and other relevant lunar events.

Because the Moon is the most frequently observed celestial object, this feature should remain simple, informative and visually engaging.

---

## Telescope Calculator

This interactive tool helps users understand how different telescope configurations affect astronomical observation.

Rather than requiring advanced technical knowledge, the calculator should encourage experimentation and make telescope concepts easier to understand.

---

## NASA Images

This section showcases astronomy images provided by NASA.

Every image should include scientific context, allowing users not only to admire the beauty of the universe but also to understand what they are seeing.

---

## User Profile

The profile allows users to personalize their AstroAlert experience.

Saved observations, preferences and future personalized features are managed here.

The profile should remain simple and never distract from the application's primary purpose.

---

## Community *(Future Feature)*

The Community section will allow astronomy enthusiasts to exchange knowledge, share observations and discuss astronomical events.

Community interaction should always support learning and discovery rather than becoming the main focus of the platform.

The universe remains the protagonist.

---

# Design Implications

Every feature included in AstroAlert should satisfy at least one of these objectives:

- Help users learn something new.
- Encourage exploration.
- Support real astronomical observation.
- Present reliable scientific information.
- Inspire curiosity.
- Create meaningful interaction with the universe.

If a feature cannot clearly support one or more of these objectives, it should not become part of AstroAlert.

---

# Final Statement

AstroAlert is not a collection of independent tools.

It is a unified experience where every feature contributes to a single mission:

Helping people understand, observe and appreciate the universe.

Every section represents a different path toward the same destination.

Curiosity.
