# Home Page

> "The first step into the universe begins with curiosity."

---

# Purpose

The AstroAlert Home Page is the main entrance to the astronomical experience.

Its purpose is to introduce users to the universe through a calm, elegant and meaningful first interaction.

The Home Page should communicate:

- What AstroAlert is.
- What is currently happening in the universe.
- What users can explore.

The goal is to transform curiosity into discovery.

---

# Experience Philosophy

The Home Page is not a traditional dashboard.

It is an invitation to explore.

The experience should feel like opening a window into the universe.

The user should immediately feel:

- Curiosity.
- Wonder.
- Trust.
- Desire to learn.

The interface should remain simple while creating a sense of depth and discovery.

---

# User Journey

The Home experience follows this path:

```
Curiosity

↓

Discovery

↓

Understanding

↓

Exploration

↓

Connection
```

Each section should guide the user naturally through this journey.

---

# Page Structure

The Home Page is composed of meaningful sections.

Each section must have a clear purpose.

No element should exist only for decoration.

---

# Section 1 — Cosmic Hero

## Purpose

Create the first emotional connection with AstroAlert.

## Content

Contains:

- AstroAlert identity.
- Main message.
- Primary exploration action.
- Astronomical visual environment.

## Goal

The user should understand the product within seconds.

Example:

"Explore the universe, discover astronomical events, and understand what is happening beyond Earth."

---

# Section 2 — Universe Status

## Purpose

Present real-time information about the universe.

Possible information:

- Moon phase.
- Visible planets.
- ISS location.
- Upcoming astronomical events.

## Goal

Make users feel that the universe is alive and constantly changing.

---

# Section 3 — Featured Discovery

## Purpose

Highlight an important astronomical topic.

Examples:

- A planet.
- A space mission.
- A scientific discovery.
- An astronomical image.

## Content

Contains:

- Visual element.
- Short explanation.
- Exploration action.

## Goal

Create curiosity and encourage deeper exploration.

---

# Section 4 — Exploration Areas

## Purpose

Introduce the main AstroAlert experiences.

Main sections:

- Planets.
- ISS.
- Eclipses.
- Telescope.
- Discover.

## Goal

Allow users to choose their own path through astronomy.

---

# Section 5 — Observation Connection

## Purpose

Connect digital knowledge with real-world observation.

Possible content:

- What can be seen tonight.
- Observation recommendations.
- Telescope guidance.

## Goal

Encourage users to look at the real sky.

---

# Section 6 — Community

## Purpose

Create a shared space for astronomy enthusiasts.

Possible content:

- Discussions.
- User observations.
- Shared discoveries.

## Goal

Transform astronomy into a collaborative experience.

# Visual Direction

The Home Page follows the Cosmic Glass design language.

---

# Atmosphere

The visual environment should feel:

- Deep.
- Calm.
- Scientific.
- Elegant.

The background should create the feeling of space while maintaining readability.

---

# Information Hierarchy

Priority order:

1. Important astronomical information.
2. Current discoveries.
3. Exploration opportunities.
4. Additional content.

The most valuable information must always be visible first.

---

# Motion Principles

Animations should communicate:

- Depth.
- Discovery.
- Movement.

Avoid:

- Excessive effects.
- Constant movement.
- Visual distractions.

Motion exists to support understanding.

---

# Responsive Behavior

## Desktop

The experience can use large visual spaces and immersive layouts.

---

## Mobile

The experience prioritizes:

- Essential information.
- Clear actions.
- Simple exploration.

The feeling of AstroAlert must remain consistent.

---

# Accessibility

The Home Page must support:

- Clear information hierarchy.
- Readable typography.
- Alternative text for images.
- Accessible navigation.
- Comfortable interaction.

Astronomy should be available to everyone.

---

# Success Criteria

The Home Page succeeds when users think:

"I want to discover more."

After visiting the page, users should understand:

- What AstroAlert represents.
- What is happening in the universe.
- Where they can continue exploring.

---

# Final Statement

The Home Page is not just the beginning of the application.

It is the first connection between humans and the universe.

It transforms curiosity into exploration.
