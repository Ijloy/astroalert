# Modal Components

> "Some discoveries deserve a closer look."

---

# Purpose

Modal components provide focused experiences where users can explore additional information, confirm actions or interact with specialized content.

A modal creates a temporary focused environment without leaving the current experience.

In AstroAlert, modals are used for:

- Deeper exploration.
- Important information.
- Focused interactions.
- Additional context.

A modal should create depth, not interruption.

---

# Content

# Modal Philosophy

AstroAlert follows the Cosmic Glass principle:

A modal is a temporary window into deeper knowledge.

It should feel like:

- Opening a scientific instrument.
- Examining a discovery.
- Looking closer at an astronomical object.

It should not feel like:

- A warning popup.
- An advertisement.
- A forced interruption.

---

# When To Use A Modal

A modal should only appear when the information or action requires focus.

Good examples:

- Viewing detailed planet information.
- Exploring a telescope configuration.
- Enlarging astronomical images.
- Confirming important settings.

---

# When Not To Use A Modal

Avoid using modals for:

- Long articles.
- Main experiences.
- Essential navigation.
- Information users need frequently.

If something is central to the experience, it deserves its own page.

---

# Modal Anatomy

Every modal contains:

---

# Header

Purpose:

Identify the current focus.

Contains:

- Title.
- Optional icon.
- Close action.

The user should immediately understand what they opened.

---

# Content Area

Purpose:

Present focused information.

Examples:

- Scientific explanation.
- Image.
- Data.
- Configuration.

Content should remain organized.

---

# Action Area

Purpose:

Provide next steps.

Examples:

- Explore.
- Save.
- Continue.
- Close.

Actions should be clear.

---

# Modal Types

---

# Information Modal

## Purpose

Display additional knowledge.

Examples:

- Planet details.
- Scientific explanations.
- Historical context.

Characteristics:

Focus on learning.

---

# Image Modal

## Purpose

Provide a closer view of astronomical imagery.

Examples:

- Galaxy images.
- Planet photographs.
- Telescope captures.

Characteristics:

The image becomes the main experience.

---

# Configuration Modal

## Purpose

Allow users to customize an experience.

Examples:

- Telescope settings.
- Observation preferences.

Characteristics:

Clear steps and guidance.

---

# Confirmation Modal

## Purpose

Confirm important actions.

Examples:

- Removing saved objects.
- Changing important preferences.

Characteristics:

Used carefully.

Avoid unnecessary confirmations.

---

# Modal Behavior

## Opening

The transition should feel natural.

The user should understand:

"Something deeper is being revealed."

---

## Closing

The user should easily return to the previous context.

The experience should not feel interrupted.

---

# Motion

Modal animations follow the Motion System.

Characteristics:

- Smooth appearance.
- Controlled movement.
- Clear focus transition.

Avoid:

- Aggressive effects.
- Long animations.

---

# Visual Style

Modals follow Cosmic Glass.

Characteristics:

## Layer Separation

The modal should feel like a separate layer.

---

## Transparency

Use subtle glass effects.

Avoid reducing readability.

---

## Focus

The background should become secondary.

The modal content becomes the main focus.

---

# Modal Content Rules

## Rule 1

One modal should have one main purpose.

---

## Rule 2

Do not overload the user with information.

---

## Rule 3

Important actions must be obvious.

---

## Rule 4

The user must always know how to exit.

# Accessibility

Modals must support:

- Keyboard navigation.
- Focus management.
- Screen readers.
- Clear close actions.

When opened, user attention should move naturally into the modal.

---

# Responsive Behavior

Desktop:

Can provide richer content.

Mobile:

Must prioritize:

- Essential information.
- Simple actions.
- Easy closing.

---

# Design Implications

Modal components affect:

- Exploration experiences.
- Learning sections.
- Configuration tools.
- Astronomy visualizations.

A modal should only exist when focus improves the experience.
