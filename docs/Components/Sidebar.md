# Sidebar Component

> "Navigation is the spacecraft that guides exploration."

---

# Purpose

The AstroAlert Sidebar provides access to the main experiences of the platform.

It allows users to move between different areas of exploration while maintaining visual focus on astronomical content.

The Sidebar is not only a navigation element.

It represents the user's connection point with the AstroAlert universe.

Its purpose is to provide:

- Orientation.
- Accessibility.
- Exploration.
- Consistency.

---

# Content

# Sidebar Philosophy

The AstroAlert Sidebar follows the Cosmic Glass principle:

Navigation should feel present, but never dominant.

The universe is the main experience.

The Sidebar is only the instrument that helps users explore it.

It should feel:

- Lightweight.
- Elegant.
- Scientific.
- Calm.

It should not feel:

- Heavy.
- Distracting.
- Like a traditional administration panel.

---

# Sidebar Structure

The Sidebar is divided into four main areas.

---

# 1. Brand Area

## Purpose

Establish AstroAlert identity.

Contains:

- Logo.
- Product name.
- Optional short description.

The brand area should create recognition without occupying excessive space.

---

# 2. Main Navigation

## Purpose

Provide access to primary experiences.

Possible sections:

```
Home

Discover

Planets

ISS

Eclipses

Telescope

Community
```

Each section represents a different way to experience astronomy.

---

# 3. Secondary Navigation

## Purpose

Provide additional tools.

Examples:

- Search.
- Favorites.
- Notifications.
- Settings.

These actions should remain visually secondary.

---

# 4. User Area

## Purpose

Represent the user within AstroAlert.

Contains:

- Profile.
- Preferences.
- Learning progress.

The user experience should feel personal without becoming a social network.

---

# Navigation Items

Every navigation item contains:

## Icon

Purpose:

Provide fast recognition.

Icons should be:

- Simple.
- Consistent.
- Scientific inspired.

---

## Label

Purpose:

Explain the destination.

Labels should be:

- Short.
- Clear.
- Understandable.

Avoid technical names.

---

## Active State

The current location must always be visible.

The active state should communicate:

"I am here."

Without becoming visually aggressive.

---

# Sidebar Behavior

## Desktop

The Sidebar remains visible.

Purpose:

Provide constant access to exploration.

---

## Tablet

The Sidebar may become compact.

The experience should maintain clarity.

---

## Mobile

The Sidebar transforms into a mobile navigation pattern.

Priority:

- Easy access.
- Minimal space usage.
- Clear actions.

---

# Interaction Patterns

## Opening and Closing

The Sidebar movement should follow the Motion System.

It should feel like:

- A panel revealing information.
- A system activating.

Not:

- A webpage menu appearing.

---

## Hover

Hover states should be subtle.

Possible feedback:

- Soft illumination.
- Slight background change.
- Clear focus.

---

## Selection

Selecting a section should immediately communicate the destination.

---

# Visual Style

The Sidebar follows Cosmic Glass principles:

## Transparency

The panel may use:

- Glass effect.
- Soft blur.
- Layer separation.

---

## Depth

Depth should be created through:

- Contrast.
- Light.
- Layering.

Avoid heavy shadows.

---

## Space

The Sidebar should have breathing room.

Items should never feel compressed.

---

# Navigation Rules

## Rule 1

The user must always know where they are.

---

## Rule 2

Navigation should not compete with content.

---

## Rule 3

The number of primary options should remain limited.

Too many destinations create confusion.

---

## Rule 4

New sections should only be added when they represent a meaningful experience.

---

# Accessibility

The Sidebar must support:

- Keyboard navigation.
- Clear focus states.
- Screen readers.
- Logical navigation order.

Navigation should never depend only on visual appearance.

The Sidebar affects:

- Application structure.
- User flows.
- Page transitions.
- Responsive behavior.

Every new section added to AstroAlert must consider its relationship with navigation.
