# Timeline Component

> "The universe is a story written through time."

---

# Purpose

The Timeline component represents chronological information in a visual and interactive way.

It allows users to explore relationships between:

- Events.
- Discoveries.
- Missions.
- Astronomical phenomena.
- Scientific progress.

The Timeline transforms dates into experiences.

It helps users understand not only:

"What happened?"

but also:

"Why does it matter?"

---

# Content

# Timeline Philosophy

AstroAlert uses timelines as exploration tools.

A timeline should not feel like a list of dates.

It should feel like traveling through moments of discovery.

The experience should communicate:

- Progress.
- Connection.
- Evolution.
- Context.

---

# Timeline Types

AstroAlert uses different timeline patterns depending on the purpose.

---

# Historical Timeline

## Purpose

Show important moments from astronomy history.

Examples:

- First telescope observations.
- Space missions.
- Scientific discoveries.

## Experience

Users explore how humanity's understanding of the universe evolved.

---

# Astronomical Event Timeline

## Purpose

Display upcoming or past astronomical events.

Examples:

- Solar eclipses.
- Lunar eclipses.
- Meteor showers.
- Planetary alignments.

## Experience

Users understand when events happen and why they matter.

---

# Mission Timeline

## Purpose

Represent space exploration journeys.

Examples:

- Launch.
- Important milestones.
- Discoveries.
- Current status.

---

# Scientific Evolution Timeline

## Purpose

Explain how astronomical knowledge develops.

Examples:

- Ancient observations.
- Modern telescopes.
- Future discoveries.

---

# Timeline Anatomy

A Timeline contains:

---

# Timeline Axis

## Purpose

Creates the relationship between events.

The axis represents:

- Time.
- Progress.
- Connection.

---

# Timeline Point

## Purpose

Represent a specific moment.

Contains:

- Date.
- Title.
- Short description.

---

# Timeline Card

## Purpose

Provide additional context.

Contains:

- Image.
- Explanation.
- Related information.

---

# Timeline Indicator

## Purpose

Show the user's current position.

Examples:

- Current date.
- Active event.
- Selected moment.

---

# Interaction Behavior

## Exploration

Users can move through events naturally.

The experience should encourage curiosity.

---

## Selection

Selecting an event reveals deeper information.

Possible actions:

- Open details.
- View images.
- Explore related topics.

---

## Progress

For educational experiences, the timeline can represent learning progression.

Example:

```
Basic Astronomy

↓

Solar System

↓

Stars

↓

Galaxies

↓

Universe
```

---

# Visual Style

Timeline follows Cosmic Glass principles.

---

# Depth

Events should feel like floating points in space.

Use:

- Layering.
- Soft separation.
- Atmospheric depth.

---

# Connection

The timeline line represents continuity.

It should feel organic.

Not like a business chart.

---

# Spacing

Events require breathing room.

The user should understand each moment individually.

---

# Motion

Timeline movement follows the Motion System.

Possible behaviors:

- Smooth scrolling.
- Event revealing.
- Focus transitions.

Motion should help users understand time.

---

# Timeline Rules

## Rule 1

Every event must have meaning.

---

## Rule 2

Avoid displaying too many events simultaneously.

---

## Rule 3

Important moments should receive stronger visual emphasis.

---

## Rule 4

Dates should always include context.

A date alone is not knowledge.

# Accessibility

Timeline must support:

- Keyboard navigation.
- Alternative text.
- Clear chronological order.
- Screen reader interpretation.

Users should not depend only on visual positioning.

---

# Responsive Behavior

Desktop:

Can show larger chronological experiences.

Mobile:

Should transform into:

- Vertical timeline.
- Simplified navigation.
- Clear reading order.

---

# Design Implications

Timeline affects:

- Educational experiences.
- Historical sections.
- Event pages.
- Discovery journeys.

New timelines should only exist when time relationships improve understanding.

---

# Final Statement

A timeline is not a measurement of time.

It is a way to understand our place inside it.

AstroAlert uses timelines to transform history into exploration.
