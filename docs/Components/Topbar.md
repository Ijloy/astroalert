# Topbar Component

> "A mission begins with knowing where you are."

---

# Purpose

The AstroAlert Topbar provides contextual information and quick access to important actions.

It helps users understand their current experience while keeping essential tools available.

The Topbar is not a navigation replacement.

Its purpose is to provide:

- Context.
- Awareness.
- Quick actions.
- User control.

---

# Content

# Topbar Philosophy

The Topbar follows the Cosmic Glass principle:

Important information should be visible, but never overwhelming.

It should feel like a scientific interface:

- Precise.
- Minimal.
- Calm.
- Intelligent.

The Topbar should never compete with astronomical content.

The universe remains the main focus.

---

# Topbar Structure

The Topbar contains four possible areas.

---

# 1. Context Area

## Purpose

Show the user's current location inside AstroAlert.

Examples:

```
AstroAlert / Planets / Mars
```

or:

```
Tonight's Sky
```

This helps users maintain orientation.

---

# 2. Current Information Area

## Purpose

Display relevant real-time information.

Examples:

- Current astronomical event.
- Moon phase.
- ISS visibility.
- Observation conditions.

This area changes depending on the current experience.

---

# 3. Action Area

## Purpose

Provide quick access to useful actions.

Examples:

- Search.
- Notifications.
- Favorites.
- Share.

Actions should remain secondary.

---

# 4. User Area

## Purpose

Provide access to personal settings and preferences.

Contains:

- Profile.
- Account settings.
- Personal discoveries.

The user area should feel like a connection point, not an administration panel.

---

# Topbar Variations

The Topbar adapts depending on the experience.

---

# Visual Style

The Topbar follows Cosmic Glass.

---

# Glass Layer

Possible characteristics:

- Transparency.
- Blur.
- Subtle separation from background.

Purpose:

Create depth without heaviness.

---

# Spacing

The Topbar must have enough breathing room.

Avoid:

- Crowded icons.
- Excessive information.
- Small unreadable text.

---

# Typography

Hierarchy:

Primary:

Current location or experience.

Secondary:

Supporting information.

Tertiary:

Metadata.

---

# Interaction Patterns

## Search

Search should feel like discovery.

It should allow users to find:

- Planets.
- Events.
- Topics.
- Objects.

---

## Notifications

Notifications should represent meaningful astronomical moments.

Examples:

Good:

"Solar eclipse visible in your region tomorrow."

Bad:

"Open the app now."

---

## User Actions

Actions should be predictable and subtle.

The user should always understand what they do.

---

# Responsive Behavior

## Desktop

Full Topbar experience.

Provides context and quick actions.

---

## Tablet

Reduced information.

Maintains essential actions.

---

## Mobile

Prioritizes:

- Current section.
- Search.
- Main action.

Secondary information may move elsewhere.

---

# Topbar Rules

## Rule 1

Never hide important astronomical information.

---

## Rule 2

Do not fill the Topbar with unnecessary controls.

---

## Rule 3

The Topbar supports exploration.

It does not become the exploration.

---

## Rule 4

Context should always be clear.

Users should know where they are.

---

# Accessibility

The Topbar must support:

- Keyboard navigation.
- Screen readers.
- Clear labels.
- Logical focus order.

Important information must not depend only on icons.
