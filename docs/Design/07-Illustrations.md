# Illustration System

> "The universe does not need to be exaggerated. It only needs to be revealed."

---

# Purpose

The AstroAlert Illustration System defines how visual representations of astronomical concepts are created and used throughout the platform.

Illustrations exist to improve understanding, create emotional connection and guide exploration.

They are not decorative elements.

Every visual representation must support one of these purposes:

- Explain.
- Guide.
- Inspire.
- Clarify.

The universe itself is the main visual inspiration.

---

# Content

# Illustration Philosophy

AstroAlert combines three types of visual resources:

1. Real astronomical imagery.
2. Scientific visualizations.
3. Designed illustrations.

Each one has a specific purpose.

The choice between them should always be intentional.

---

# Real Astronomical Imagery

## Purpose

Show the authentic beauty of the universe.

## Usage

Examples:

- Galaxies.
- Nebulas.
- Planet photography.
- Space missions.
- Astronomical events.

## Principles

Real images should preserve:

- Scientific accuracy.
- Context.
- Source credibility.

The image should not only be beautiful.

The user should understand what they are seeing.

---

# Scientific Visualization

## Purpose

Explain concepts that cannot be easily understood through photography.

## Usage

Examples:

- Planetary orbits.
- Eclipse alignment.
- Telescope concepts.
- Space trajectories.

## Principles

Visual accuracy is more important than visual realism.

The objective is understanding.

---

# Designed Illustration

## Purpose

Create emotional moments and improve interaction.

## Usage

Examples:

- Empty states.
- Educational sections.
- Onboarding experiences.
- Friendly explanations.

## Principles

Illustrations should feel:

- Elegant.
- Modern.
- Scientific.
- Calm.

---

# Illustration Style

Cosmic Glass illustrations follow these characteristics:

## Minimal Complexity

Avoid unnecessary details.

The universe is complex.

The illustration should make it understandable.

---

## Soft Depth

Use:

- Layers.
- Light.
- Transparency.
- Atmospheric effects.

Avoid:

- Heavy shadows.
- Excessive 3D effects.

---

## Scientific Elegance

Illustrations should feel closer to:

- Scientific visualization.
- Modern technology.
- Premium interfaces.

Not:

- Fantasy art.
- Cartoon space themes.
- Futuristic decoration.

---

# Astronomical Objects Representation

## Planets

Planets should communicate:

- Scale.
- Identity.
- Characteristics.

Avoid unrealistic colors or exaggerated appearances.

---

## Stars

Stars should represent:

- Light.
- Distance.
- Discovery.

Avoid filling backgrounds with unnecessary stars.

---

## Galaxies

Galaxies represent:

- Scale.
- Wonder.
- Exploration.

They should create emotion while maintaining scientific credibility.

---

## Spacecraft and Satellites

Represent:

- Human exploration.
- Technology.
- Engineering achievement.

They should communicate purpose.

---

# Image Usage Principles

## Rule 1

Real astronomical imagery has priority when available.

---

## Rule 2

Visual beauty should never replace scientific accuracy.

---

## Rule 3

Every image must have context.

A beautiful image without explanation is only decoration.

---

## Rule 4

Avoid visual overload.

One powerful image is better than many average ones.

---

# Hero Visuals

Large visual areas can be used for important experiences.

Examples:

- Major discoveries.
- Featured astronomical events.
- Educational introductions.

Hero visuals should create:

- Curiosity.
- Scale.
- Emotional connection.

---

# Background Visuals

Backgrounds should support the interface.

They should:

- Create atmosphere.
- Add depth.
- Maintain readability.

They should never reduce content visibility.

---

# Empty States

Empty states should maintain the AstroAlert personality.

They should feel:

- Calm.
- Encouraging.
- Curious.

Example:

Instead of:

"No data available"

The experience should communicate:

"Nothing to observe right now. The universe continues moving."

---

# Design Implications

The Illustration System affects:

- Landing pages.
- Educational experiences.
- Astronomy sections.
- Empty states.
- Onboarding.
- Marketing materials.

Every visual should strengthen the relationship between humans and astronomy.

---

# Final Statement

Illustrations in AstroAlert are not windows to imaginary worlds.

They are tools that help people understand the real universe.

The goal is not to create a fantasy of space.

The goal is to make the true universe feel closer.
