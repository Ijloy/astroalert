# User Flows

> "Every journey begins with curiosity."

---

# Purpose

The AstroAlert User Flows define how users move through the platform and experience astronomical discovery.

These flows describe the relationship between:

- User intention.
- Information.
- Exploration.
- Interaction.

The goal is not to create a fixed path.

The goal is to create natural journeys where users can discover the universe at their own pace.

AstroAlert should always answer:

"What brought the user here, and what should happen next?"

---

# Content

# Flow Philosophy

Users do not think in features.

They think in goals.

They do not think:

"I want to open the Planet module."

They think:

"I want to know more about Mars."

"I want to see what I can observe tonight."

"I want to understand this eclipse."

"I want to discover something new."

The experience should start from curiosity and lead toward exploration.

# Primary User Flows

---

# Flow 1 — First Discovery Experience

## User Goal

Understand what AstroAlert offers and discover the universe.

## Journey

```
Landing Page

↓

Introduction to AstroAlert

↓

Current astronomical highlights

↓

Explore universe sections

↓

Discover first topic
```

## Experience Objective

The user should understand within seconds:

- What AstroAlert is.
- Why it exists.
- What they can explore.

## Success Feeling

"I want to see more."

---

# Flow 2 — Daily Astronomy Exploration

## User Goal

Know what is happening in the universe today.

## Journey

```
Home

↓

Current Space Events

↓

Featured astronomical information

↓

Explore related topic

↓

Continue discovering
```

## Possible Experiences

- Visible planets.
- Moon phase.
- ISS visibility.
- Upcoming events.

## Experience Objective

Transform AstroAlert into a daily astronomy companion.

## Success Feeling

"I know what is happening above me."

# Flow 3 — Planet Exploration

## User Goal

Learn about a planet.

## Journey

```
Planets Section

↓

Select Planet

↓

Planet Overview

↓

Scientific Information

↓

Related Discoveries

↓
```

# Flow 4 — Astronomical Event Discovery

## User Goal

Understand an upcoming event.

Examples:

- Eclipse.
- Meteor shower.
- Planetary alignment.

## Journey

```
Event Notification

↓

Event Overview

↓

What is happening?

↓

Why does it happen?

↓

How can I observe it?
```

## Experience Objective

Transform events into learning experiences.

Not only provide dates.

## Success Feeling

"Now I understand what I am seeing."

# Universal Experience Pattern

Every AstroAlert journey should follow this structure:

```
Curiosity

↓

Discovery

↓

Understanding

↓

Exploration

↓

Inspiration
```

This pattern represents the core emotional journey of the product.

---

# Navigation Principles

Navigation should support exploration.

Users should always know:

Where they are.

What they discovered.

Where they can go next.

Navigation should never interrupt curiosity.

---

# Empty Flow States

When information is unavailable, the experience should continue.

Example:

Instead of:

"No astronomical events found."

The experience should communicate:

"No major events are visible right now. The universe continues its journey."

---

# Design Implications

User flows influence:

- Navigation.
- Page structure.
- Content hierarchy.
- Components.
- Notifications.
- Personalization.

Every feature should connect naturally with a user intention.

---

# Final Statement

AstroAlert is not a collection of destinations.

It is a journey through curiosity.

Every interaction should move users closer to understanding and appreciating the universe.
